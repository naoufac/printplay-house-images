# PrintPlayHouse — Image Repository

> **"Pure Love."** Wear what you feel.

This repository provides stable, CDN-friendly image hosting for [PrintPlayHouse.com](https://printplayhouse.com) — a playful, love-driven ecommerce clothing brand built around self-expression through print.

## Repository Structure

```
printplay-house-images/
├── {product-slug}/
│   ├── product-front.jpg          # Clean product shot (white/neutral background)
│   ├── product-detail-closeup.jpg # Close-up of print, texture, or key details
│   ├── lifestyle-secondary.jpg    # Lifestyle / in-context shot
│   └── ugc-social-media.jpg       # UGC-style or social-ready image
└── ...
```

See [`IMAGE-CONVENTIONS.md`](./IMAGE-CONVENTIONS.md) for full naming and optimization guidelines.
